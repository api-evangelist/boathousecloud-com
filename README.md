Boat House provides AI app hosting and sharing services, allowing developers to host and share applications built with Claude Code, Codex, or Cursor. The platform includes login, database, and backup features, offers open‑source tools, and a pricing model of up to five lightweight tools for $10 per month. It emphasizes easy collaboration similar to Google Docs, with a focus on AI‑driven development workflows.

**Areas:** AI · Hosting · OpenSource · Collaboration · Cloud

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Boat House: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
